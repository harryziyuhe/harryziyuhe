# Hi, I'm Harry (Ziyu) He

I'm a PhD candidate in **Data Science and Political Science at UC San Diego**, with an M.S. in Computer Science and Engineering. My work sits at the intersection of **quantitative finance, statistical learning, political economy, and applied machine learning**.

I am particularly interested in building rigorous, interpretable methods for **financial prediction, portfolio construction, time-series inference, and alternative data research**.

## Selected Projects

### [capnet](https://github.com/harryziyuhe/capnet)
An R package for **contribution-capped regularization**, extending elastic-net models with feature-level contribution constraints designed to improve robustness when individual predictors can generate outsized model exposures.

### [Expected Returns](https://github.com/JustinMShea/ExpectedReturns)
Contributor to an R package for financial time-series analysis, forecasting, and predictive modeling.

### [CongressLib](https://github.com/harryziyuhe/CongressLib)
A Python client library for the **Congress.gov API**, providing programmatic access to legislative data and utilities for downstream empirical analysis.  
Available on [PyPI](https://pypi.org/project/CongressLib/).

### [WeChat Scraping](https://github.com/harryziyuhe/wechat_scraping)
A semi-automated pipeline for collecting and processing posts from WeChat official accounts for large-scale text analysis.  
*Project archived.*
